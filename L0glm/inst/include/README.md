# Native interfaces

The installed `L0glm/scalar_families.h` header provides the shared scalar likelihood,
score and curvature calculations. `L0glm/nuisance.h` provides the small constrained
quadratic solve. Include RcppEigen first. Both are inline implementations.

`L0glm_RcppExports.h` and `L0glm.h` are generated by Rcpp attributes. The registered
C-callable background solvers retain the same implementation as the GLM fitter.
Downstream packages should list L0glm and RcppEigen in LinkingTo and L0glm in
Imports. For large matrices, pass existing SEXP arrays to the registered routines
to avoid copying Eigen maps into newly allocated R matrices.
