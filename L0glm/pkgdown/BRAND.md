# L0glm visual identity

The point-up hexagon combines a sparse spike train with a smooth fitted signal.
Midnight navy provides the foundation; cyan, mint and restrained violet connect
signal recovery with multichannel modelling. White type keeps the name readable
at sticker size.

The transparent PNG source is `man/figures/logo.png`. pkgdown derives favicons
from it and uses a copy on the website. The README uses the same source asset.

| Role | Colour |
|---|---|
| Navy | `#081629` |
| Cyan | `#43e7ec` |
| Mint | `#7aefdf` |
| Accessible teal for light backgrounds | `#087e83` |
| Violet accent | `#8b5cc7` |

The logo was created with OpenAI's built-in image generation tool. The design
brief requested a transparent regular hex sticker, a navy field, cyan/mint
spikes and fitted curve, restrained violet nodes, crisp geometric edges and
large readable `L0glm` lettering. It is an original asset for this package.

Website body text uses system fonts; mathematical notation and code remain
selectable. The layout supports keyboard navigation, responsive tables and
reduced-motion preferences.
